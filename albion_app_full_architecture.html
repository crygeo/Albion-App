Startup — Carga y arranque
1
AlbionData.StartAsync() — LibAlbionData
Localiza la instalación del juego. Descifra y cachea items.bin + localizations.bin como XDocument. Sin IO después de este paso.
2
PreloadService → Localization → Items → Categories → Achievements → CraftingLocations
Secuencial. Cada servicio reporta progreso 0-100 a la SplashWindow. FrozenDictionary construido una vez y reutilizado en toda la sesión.
LocalizationService → ItemDataService → CategoryDataService → AchievementDataService
3
EventsDbContextFactory.Create() → BuildService — SQLite (EF Core)
Abre la base de datos SQLite local. Carga Builds, BuildGroups (con slots y Build navigation property incluida vía ThenInclude), EventTemplates.
BuildsVm.LoadAsync() · GroupsVm.LoadAsync() · EventsVm.LoadAsync()
4
MainWindow.Show() → UpdateCheckService.CheckAsync() (fire-and-forget)
Llama a la API GitHub Releases. Si hay versión nueva (tag_name > Assembly version), encola snackbar "Nueva versión disponible: vX.Y.Z → VER". Timeout 5s, silencioso en fallo.
GET api.github.com/repos/crygeo/Albion-App/releases/latest
Runtime — Búsqueda de ítems (MarketVm)
5
Debounce 250ms → QueryParser.Parse(text) → SearchItemsUseCase
Descompone input en tokens + tier + enchantment. Itera SearchEntry[] del idioma activo. Batch lookup FrozenDict. Post-filtro por rango de categoría (int compare), tier, enchantment. Take(300).
ItemBase.CategoryValue ∈ [AccumulatedValue, MaxDescendantValue]
6
ItemBaseVmFactory → ImageService.GetImageBytesAsync() (fire-and-forget, semáforo 8)
Proyecta ItemBase → ItemBaseVm. Carga de imagen en background con semáforo máx 8 paralelas. Caché en disco AppData. CDN: render.albiononline.com/v1/item/
Runtime — Export de grupo como imagen
7
GroupsVm.ExportImageCommand → BuildGroupImageExporter.RenderAsync(group)
Carga imágenes de todos los slots del grupo (AlbionImageService). Construye BuildCardExportVm[] con BitmapImage? por slot. Máx 5 cards por fila (WrapPanel Width=1040).
BuildGroupExportVm { GroupName, Cards[] } → Dispatcher.InvokeAsync(RenderToImage)
8
RenderToImage() → RenderTargetBitmap (off-screen WPF)
Construye BuildGroupExportV off-screen. Measure/Arrange → DesiredSize como dimensión final. DPI detectado de la ventana activa. RenderTargetBitmap.Render() → Freeze(). ExportDialogV muestra preview con botones Copiar/Guardar PNG.
Clipboard.SetImage() · SaveFileDialog + PngBitmapEncoder
Runtime — Red (LibNetWork)
9
SharpPcapPacketProvider → AlbionParser → Handler registries
Captura paquetes UDP en background thread. AlbionParser decodifica Photon. Event handlers actualizan PlayerVm (JoinResponse) y DestinyBoardVm (AchievementHandler) vía ProcessPlayerUseCase.
NetworkManager.Start() — Task.Run, fire-and-forget, silencioso sin admin

🏗 Decisiones de arquitectura
Clean Architecture: Domain sin deps externas, Infrastructure al borde
FrozenDictionary: lock-free, O(1) lookup en listas de 20k ítems
MVVM puro: cero lógica en code-behind (solo pegamento WPF)
CategoryValue int: filtro por rango numérico, sin string comparison
ServiceBase: máquina de estados Off↔On con progreso 0-100
Off-screen render: DesiredSize > ActualWidth para WPF sin visual tree
Fire-and-forget con _ = Task: UpdateCheck, NetworkManager, ImageLoad
Composition root manual en App.xaml.cs — sin contenedor DI externo
